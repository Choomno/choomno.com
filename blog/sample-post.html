Math

Inline math sits in the sentence with single dollar signs: the golden ratio is $\varphi = \tfrac{1 + \sqrt 5}{2}$. Displayed math uses \[ … \] and gets centered on its own line:

\[ \sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}. \]

The macros defined in macros.html also work here — for instance $\abs{x}$ and $\R$ come from there.

Code

Code blocks are monospaced and scroll sideways if a line is long:

def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

Note that a dollar sign in code, like echo "$HOME", is left alone.
